# Antharangam (அந்தரங்கம்) – Official App Landing Website

A premium, modern, responsive landing website for the mobile application **Antharangam (அந்தரங்கம்)**, designed for one-to-one audio and live video conversations with verified Hosts.

## 🚀 Tech Stack

- **React.js 18**: Component-based user interface
- **Vite 6**: Fast modern bundler and development server
- **Tailwind CSS 3.4**: Utility-first styling with custom theme tokens
- **Framer Motion 11**: Fluid animations, transitions, and scroll effects
- **Lucide React**: Clean, modern iconography
- **Typography**: Plus Jakarta Sans, Inter, and Noto Sans Tamil
